# Security

Use GuardianLink only on devices you own or are explicitly authorized to manage.

Before public deployment:
- add HTTPS
- protect the dashboard with authentication
- rate-limit endpoints
- store Android tokens securely
- add audit logging
- rotate credentials

Excluded by design:
- stealth installation
- hidden persistence
- covert camera/microphone
- keylogging
- WhatsApp extraction
- credential theft
- permission bypass
- destructive remote control outside legitimate managed-device APIs
